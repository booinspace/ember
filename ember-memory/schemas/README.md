# Reserved public schemas

Memory ABI, Normalized Archive, bundle, predicate/policy, and processing-spec schemas
start in their planned phases. There are no canonical schemas in phase -1.
The reconnaissance JSON report is preparation tooling, not normalized history.

`chatgpt-source.provisional.schema.json` is generated from the phase 0a Pydantic
source-adapter models. It records public-format hypotheses and accepts unknown
provider JSON. It is not a canonical archive or Memory ABI schema; actual-export
review and phase 1 determine those contracts. The raw archive remains authoritative.
